# Portafolio de AnthoServ

Sitio profesional de **AnthoServ**, desarrollador especializado en Java,
Java EE/Jakarta EE, JSF, PrimeFaces y herramientas para desarrolladores.

## Sitio público

[anthoserv-ship-it.github.io](https://anthoserv-ship-it.github.io)

## Desarrollo local

El proyecto requiere Node.js 22 o superior.

```bash
npm install
npm run dev
```

## Validación

```bash
npm run build
npm run lint
```

Cada actualización de la rama `master` se publica automáticamente mediante
GitHub Actions y GitHub Pages.
